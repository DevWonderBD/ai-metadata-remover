# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The **AI Metadata Remover** project takes user privacy and security seriously. Because our application operates 100% within the user's web browser without transferring image data to external servers, privacy preservation is our highest priority.

If you believe you have discovered a vulnerability (such as a metadata leakage vector, memory issue, or cross-site scripting vulnerability):

1. **Do not disclose the issue publicly** on GitHub issues, pull requests, or forums.
2. Email the DevWonder security team at: **security@devwonder.com** or open a confidential advisory via GitHub's Security Advisories tab.
3. Please include:
   - A detailed description of the vulnerability.
   - Proof-of-concept steps or sample image files to reproduce.
   - Any potential impact or suggested mitigations.

We will acknowledge receipt within 48 hours and work on a resolution promptly. Thank you for helping keep our community and users secure.
